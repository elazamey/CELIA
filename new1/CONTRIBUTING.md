# المساهمة في NEW1

1. افتح Issue يصف المشكلة أو القدرة قبل التغييرات الكبيرة.
2. اقرأ `AGENTS.md` و`docs/ARCHITECTURE.md`.
3. أنشئ فرعًا صغيرًا، وأضف اختبارًا للسلوك الذي تغيّره.
4. شغّل `npm run validate` محليًا.
5. اشرح في Pull Request ما اختبرته فعلًا، وحدود الأمان، وأي تأثير على المسار المجاني.

لا ترسل مفاتيح أو ملفات `.env` أو سجلات مهام شخصية. لا تُدخل مصدر Orca أو أوزان النماذج في Git.
