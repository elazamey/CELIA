# NEW1 — مساحة وكلاء AI محلية ومجانية (v0.2.0)

**NEW1** نواة مفتوحة المصدر لبناء وكيل ذكاء اصطناعي محلي ينفّذ المهام فعليًا على ملفاتك، دون مفاتيح API أو اشتراكات سحابية. يعمل مع **Ollama** (لنماذج `8B–32B` مثل `qwen3:8b`) أو عبر **محرك CPU المدمج (`llama.cpp` + `Qwen2.5-0.5B-Instruct` بترخيص Apache-2.0)** للتشغيل الفوري، ويتكامل مع **[stablyai/orca](https://github.com/stablyai/orca)** لتنسيق مسارات `git worktree` المتوازية.

> لا اشتراك، لا مفتاح API، ولا خادم AI مدفوع. جودة المخرجات تعتمد على حجم النموذج والعتاد المتاح لديك.

## القدرات العاملة في الإصدار 0.2.0

- **بث حي للـ Tokens (Live Streaming)**: تدفق فوري للنصوص عبر NDJSON وSSE أثناء التخطيط والتنفيذ والمراجعة مع إلغاء فوري متسق (`AbortController`).
- **وكيل واحد أو فريق من 3 أدوار (`team`)**: **مخطط ← منفّذ ← مراجع** مع كشف تلقائي لتكرار الأدوات في النماذج المحلية الصغيرة.
- **7 أدوات ملفات معزولة وآمنة**: `list_files`، `read_file`، `write_file`، `edit_file` (تعديل جزئي دقيق)، `make_directory`، `delete_file`، و`search_files` — بالإضافة إلى `run_tests` الاختيارية (`npm test` فقط بـ `shell: false`).
- **موافقة بشرية قبل التعديل (`approve-writes`)**: إيقاف المهمة مؤقتًا مع معاينة الفرق (Diff Preview) قبل أي كتابة أو حذف على القرص حتى يوافق المستخدم أو يرفض.
- **حفظ السياق واستئناف المهام (`Checkpoints & Resume`)**: حفظ تلقائي لسجل المحادثة والأدوات بعد كل خطوة لاستئناف المهام المتوقفة بدل البدء من الصفر.
- **تصدير واستيراد وحذف انتقائي للذاكرة**: تصدير واستيراد السجل بصيغة JSON، حذف مهمة محددة، أو مسح المهام المنتهية.
- **نشر مستقل بنقرة واحدة أو أمر واحد**: سكربت `npm run publish:repo` (وأداة نشر مباشرة في تبويب الإعدادات) يتحقق من الحزمة المستقلة في بيئة نظيفة ويدفعها مباشرة إلى `https://github.com/elazamey/new1`.

## التشغيل السريع

### المسار أ — مع Ollama على جهازك (موصى به للمشاريع الحقيقية)

```bash
ollama pull qwen3:8b
ollama serve
npm run setup
npm start
```

### المسار ب — تشغيل فوري على المعالج دون تثبيت Ollama خارجي

ينزّل ويتحقق (SHA-256) من نموذج `Qwen2.5-0.5B-Instruct` المدمج (Apache-2.0) ويشغّل واجهة متوافقة 100% مع بروتوكول Ollama على `127.0.0.1:11434`:

```bash
npm run model:setup
npm start
```

افتح `http://localhost:3000`. نواة NEW1 نفسها مكتوبة بالكامل بوحدات Node.js 22 القياسية دون أي حزم npm خارجية مطلوبة لتشغيل الخادم أو الاختبارات.

## النشر كمستودع مستقل (`elazamey/new1`)

فور إنشاء مستودع فارغ باسم `new1` على حسابك في GitHub:

```bash
npm run publish:repo
```

أو من داخل الواجهة العربية: **الإعداد والنشر ← تحقق وانشر إلى `elazamey/new1` الآن**.

## التطوير والتحقق

```bash
npm run check          # فحص صياغة جميع الوحدات والواجهة
npm test               # تشغيل جميع الاختبارات الوحدوية والتكاملية (دون شبكة)
npm run validate       # فحص الصياغة + الاختبارات الكاملة
npm run publish:check  # اختبار بناء الحزمة المستقلة في مجلد معزول
```

## حدود الأمان

| المورد | السياسة الافتراضية |
|---|---|
| نطاق القراءة والكتابة | داخل `workspace/` فقط |
| `.git` و`.env` والروابط الرمزية | محجوبة بالكامل (`realpath` + منع الخروج من الجذر) |
| الكتابة على القرص | ذرية عبر ملف مؤقت + `rename`، مع خيار موافقة بشرية مسبقة |
| تنفيذ الأوامر | معطّل افتراضيًا؛ `npm test` فقط عند التفعيل الصريح للمهمة |
| حماية الواجهة | Same-Origin مع دعم الخوادم العكسية (`X-Forwarded-Host`) |
