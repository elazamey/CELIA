# خارطة طريق NEW1

خارطة الطريق تقيس التقدم بقدرات واختبارات، لا بمقارنات تسويقية.

## الإصدار 0.1 — النواة الحالية

- [x] Ollama محلي دون مفاتيح API.
- [x] وكيل بأدوات ملفات حقيقية.
- [x] وضع مخطط/منفّذ/مراجع.
- [x] واجهة RTL وسجل حي وإلغاء مهام.
- [x] تخزين محلي وحدود مسارات واختبارات CI.
- [x] مصدر Orca مثبت وملف مساحة عمل.

## الإصدار 0.2 — تحكم واعتمادية

- [ ] موافقة بشرية لكل كتابة حساسة وسياسات أدوات لكل مشروع.
- [ ] استئناف المهام من سياق محفوظ بدل مجرد تسجيل الانقطاع.
- [ ] دعم بث tokens مع إلغاء متسق.
- [ ] اختبارات تعاقدية مع عدة نماذج Ollama تدعم الأدوات.
- [ ] تصدير/استيراد المهام مع حذف انتقائي للذاكرة.

## الإصدار 0.3 — وكيل عام أقوى

- [ ] متصفح معزول وسياسة نطاقات واضحة.
- [ ] بحث محلي عبر SearXNG اختياري دون مزود مدفوع.
- [ ] تشغيل أوامر موسع داخل حاوية بلا صلاحيات، وليس Shell مباشرًا على المضيف.
- [ ] أدوات مستندات وصور حسب قدرة النموذج المحلي.
- [ ] ربط Orca Worktrees بمهام الفريق مع مراجعة ودمج بشريين.

## الإصدار 0.4 — تقييم قابل للمقارنة

- [ ] مجموعة مهام عربية وإنجليزية قابلة لإعادة التشغيل.
- [ ] قياس النجاح والزمن والذاكرة والطاقة لكل نموذج.
- [ ] نشر نتائج سلبية وإيجابية بلا انتقاء.
- [ ] مقارنات منصفة بالأدوات والسياق والميزانية نفسها.

## مبادئ ثابتة

1. المسار المحلي المجاني يبقى صالحًا دون تسجيل.
2. لا تُضاف تتبعات أو قياسات استخدام خفية.
3. لا يُعلن إنجاز قبل اختبار فعلي.
4. المستخدم يملك ملفاته وسجله ويمكنه حذفها.
5. الأمان والمصادقة مطلوبان قبل وصف النسخة بأنها خدمة متعددة المستخدمين.
