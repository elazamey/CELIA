خارطة الطريق تقيس التقدم بقدرات فعلية مغطاة بالاختبارات، لا بمقارنات تسويقية.

- [x] وكيل بأدوات ملفات حقيقية.
- [x] وضع مخطط/منفّذ/مراجع.
- [x] واجهة RTL وسجل حي وإلغاء مهام.
- [x] تخزين محلي وحدود مسارات واختبارات CI.
- [x] مصدر Orca مثبت وملف مساحة عمل.
