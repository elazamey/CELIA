الإعداد والتكامل

كل ما تحتاجه لتشغيل NEW1 وتطويره على جهازك.

01

شغّل النموذج المحلي

ثبّت Ollama، ثم نزّل النموذج وشغّل الخدمة. يمكنك اختيار أي نموذج آخر مثبت لديك.

ollama pull qwen3:8b ollama serve
جارٍ قراءة حالة المزود…
02

اربط Orca

يجلب هذا الأمر المصدر MIT الرسمي إلى vendor/orca بإصدار مثبت، لتستخدم تنسيق Worktrees وتطبيق سطح المكتب.

npm run orca:init
جارٍ فحص مصدر Orca…
03

اختبر قبل التطوير

النواة بلا اعتماديات npm خارجية. اختبارات الأدوات والتخزين والخادم تعمل مباشرة على Node.js 22+.

npm run validate
ملفاتك ومهامك لا تغادر الجهاز عبر NEW1.
04

ماذا يعني «مجاني»؟

لا رسوم ترخيص أو اشتراكات أو واجهات API مدفوعة في هذا المسار. تحتاج فقط جهازًا قادرًا على تشغيل النموذج، وتحتمل تكلفة الكهرباء والعتاد.

الجودة تعتمد على النموذج والعتاد؛ NEW1 أساس قابل للتطوير وليس ادعاءً باجتياز Claude أو Manus في كل المهام.
