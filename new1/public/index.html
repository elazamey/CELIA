01
النموذج المحلي (Ollama أو المحرك المدمج)
يعمل الآن محرك GGUF CPU المدمج (qwen2.5:0.5b-instruct بترخيص Apache-2.0) تلقائيًا، ويمكنك على جهازك تشغيل نماذج أكبر مثل qwen3:8b عبر Ollama الرسمي.
ollama pull qwen3:8b
ollama serve
جارٍ قراءة حالة المزود…

            
02
اربط منصة Orca
يتعرف الخادم تلقائيًا على وحدة orca الفرعية في CELIA أو يجلب المصدر الرسمي المثبت إلى vendor/orca لتشغيل مسارات Worktrees متوازية.
npm run orca:init
جارٍ فحص مصدر Orca…

            
03
اختبر قبل التطوير
نواة NEW1 بلا اعتماديات npm خارجية؛ تشمل الاختبارات عزل المسارات، الموافقات البشرية، استئناف السياق، وبث SSE.
npm run validate
ملفاتك ومهامك لا تغادر الجهاز عبر NEW1.

            
04
الشفافية الهندسية: ماذا يعني «مجاني»؟
الكود مفتوح المصدر بترخيص MIT ولا يتطلب اشتراكًا أو مفتاح API. المحرك المدمج يستخدم Qwen2.5-0.5B-Instruct (مناسب للمهام السريعة والتجربة الفورية).
للمشاريع البرمجية المعقدة، شغّل نموذجًا بحجم 8B–32B عبر Ollama على جهازك؛ جودة المخرجات تعتمد على حجم النموذج والعتاد.
